## 🧠 Функціонал проєкту

- 🖼️ **Завантаження SEM-зображень** у форматах PNG, JPG, JPEG, BMP, TIFF
- ✏️ **Ручна розмітка частинок** полігонами без зовнішніх інструментів
- 💾 **Збереження та завантаження розмітки** у JSON-файлі
- 🔍 **Масштабування і переміщення зображення** для зручної роботи з великими SEM-знімками
- ⚙️ **Вибір підходу сегментації** та зміна ключових параметрів
- 🧪 **Класичні методи OpenCV**: Otsu + morphology, Adaptive threshold, Hough circles
- 🧬 **Нейромережевий підхід U-Net** із навчанням на ручній розмітці
- 🔄 **Data augmentation** для збільшення навчального набору U-Net
- 📏 **Вимірювання частинок**: площа, еквівалентний діаметр, круглість, bounding box
- 📊 **Побудова графіка Particle Size Distribution** за CSV-файлом
- 📁 **Експорт результатів**: зображення з контурами, маска, CSV, графік

## ▶️ Як запустити програму

### 1. Встановлення Python

Потрібно встановити **Python 3.10 або новішу версію**.

Перевірити версію можна командою:

```bash
python --version
```

### 2. Клонування репозиторію

```bash
git clone https://github.com/Ostap8943/sem-particle-segmentation-lab.git
cd sem-particle-segmentation-lab
```

### 3. Створення віртуального середовища

Рекомендовано запускати проєкт у віртуальному середовищі Python.

#### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

#### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Встановлення залежностей

```bash
pip install -r requirements.txt
```

Якщо файл `requirements.txt` недоступний, залежності можна встановити вручну:

```bash
pip install opencv-python numpy pillow matplotlib torch torchvision
```

### 5. Запуск

```bash
python main.py
```

Після запуску відкриється вікно програми **SEM Particle Segmentation Lab**.

> Примітка: тестові SEM-зображення не входять до репозиторію. Для роботи програми потрібно відкрити власне SEM-зображення через кнопку **Відкрити SEM**.

## 🖥️ Інструкція користувача

1. Натиснути **Відкрити SEM** і вибрати SEM-зображення.
2. За потреби натиснути **Малювати** та вручну обвести частинки полігонами.
3. Для переміщення зображення використати режим **Рух фото**.
4. У правій панелі вибрати підхід сегментації.
5. Налаштувати параметри вибраного методу.
6. Для U-Net спочатку створити ручну розмітку та натиснути **Навчити U-Net**.
7. Натиснути **Запустити аналіз**.
8. Переглянути знайдені контури, таблицю результатів і статистику.
9. Натиснути **Зберегти результат** для експорту файлів.

## 🧪 Реалізовані методи сегментації

| Метод | Призначення | Основні параметри |
|---|---|---|
| `Otsu + morphology` | Швидка сегментація контрастних частинок на фоні | згладжування, мінімальна площа, морфологія |
| `Adaptive threshold` | Локальне порогування для зображень із нерівномірною яскравістю | adaptive block, adaptive C, мінімальна площа |
| `Hough circles` | Виявлення круглих або близьких до круглих частинок | чутливість, мінімальний радіус, максимальний радіус |
| `U-Net neural network` | Нейромережева сегментація на основі ручної розмітки | U-Net поріг, кількість епох, data augmentation |

## 📐 Параметри, що обчислюються

| Показник | Опис |
|---|---|
| `area_px` | Площа знайденої частинки у пікселях |
| `equivalent_diameter_px` | Діаметр кола з такою самою площею, як знайдена частинка |
| `circularity` | Оцінка круглісті контуру |
| `bbox` | Прямокутна рамка навколо частинки |
| `particle_count` | Кількість знайдених частинок |
| `mask_coverage` | Частка зображення, яку алгоритм відніс до частинок |
| `mean_area` | Середня площа знайдених частинок |
| `median_area` | Медіана площі знайдених частинок |
| `mean_equivalent_diameter` | Середній еквівалентний діаметр |

## 📊 Графік розподілу розмірів

Програма будує графік **Particle Size Distribution** на основі стовпця `equivalent_diameter_px` з CSV-файлу.

На графіку:

- вісь X показує еквівалентний діаметр частинок у пікселях;
- вісь Y показує кількість частинок у відповідному діапазоні;
- вертикальні лінії позначають середнє значення та медіану.

Такий графік використовується для кількісного аналізу результату сегментації та порівняння поведінки різних методів.

## 🔬 Особливості U-Net

Для навчання U-Net користувач вручну обводить частинки на SEM-зображенні. З цих полігонів формується бінарна маска, яка використовується як навчальна розмітка.

Data augmentation може створювати додаткові варіанти навчальних зразків за рахунок поворотів, віддзеркалення та зміни вигляду зображення. Це корисно тоді, коли ручної розмітки небагато.

Якість U-Net залежить від:

- кількості розмічених частинок;
- точності ручної розмітки;
- кількості епох навчання;
- порогу перетворення ймовірнісної карти в маску;
- схожості тестового зображення на навчальні приклади.

## 🧪 Проблеми і рішення

| Проблема | Можлива причина | Рішення |
|---|---|---|
| Метод знаходить занадто мало частинок | Завеликий поріг або мінімальна площа | Зменшити поріг або мінімальну площу |
| Метод знаходить багато шуму | Замала мінімальна площа або слабка фільтрація | Збільшити мінімальну площу або морфологію |
| Adaptive threshold дає багато дрібних фрагментів | Невдалий `adaptive block` або `adaptive C` | Підібрати локальні параметри порогу |
| Hough circles пропускає частинки | Неправильний діапазон радіусів | Змінити мінімальний і максимальний радіус |
| U-Net не знаходить частинки | Недостатньо ручної розмітки або невдалий поріг | Додати більше полігонів, увімкнути augmentation, змінити U-Net поріг |
| Результат U-Net фрагментований | Мало прикладів або контури розмічені нерівномірно | Розмітити більше частинок різного розміру |
| Не зберігається результат | Немає доступу до папки або файл відкритий іншою програмою | Вибрати іншу папку або закрити відкритий файл |
